Detailed Description

Raw Ethernet access to the WiFi network through the ESP32's station.

Joins the network and then takes over frame reception from the IP stack (esp_wifi_internal_reg_rxcb), so everything the station receives is passed to the FrameReceiver, and sends frames with esp_wifi_internal_tx(). The station's own DHCP client is stopped: the MCU has no IP address, the host behind the bridge uses the station's MAC address and asks the network itself.

Also an Uplink, so the composition can report the association state.

◆ macAddress()

const uint8_t * twd::Esp32WifiFrameLink::macAddress ( )
inlineoverridevirtual

The station MAC as the WiFi stack reports it. On chips with their own radio this equals the MAC from the chip's fuses; on the ESP32-P4 the radio sits in a companion chip (ESP-Hosted), whose MAC is the one the access point sees. Starts the WiFi stack on the first call, so it must not be called from a time-critical path before begin(); the result is cached.
