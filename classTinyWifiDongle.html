Detailed Description

Shares the microcontroller's WiFi connection with a USB host.

Thin facade over the port of the MCU in use (TinyWifiDonglePort): the microcontroller joins a WiFi network and appears to the host as a USB network adapter that is bridged to the WiFi network.

TinyWifiDongle dongle;
void setup() { dongle.begin("ssid", "password"); }
void loop() {}
