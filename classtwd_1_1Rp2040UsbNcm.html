Detailed Description

USB CDC-NCM network device for the Raspberry Pi Pico W / Pico 2 W.

Implements UsbTransport on top of the TinyUSB NCM class of the arduino-pico core (USB stack "Pico SDK"). Frames from the host are queued by the TinyUSB receive callback and handed to the FrameReceiver by a worker in the core's lwIP async context; frames to the host are queued by send() and pushed into the USB stack by the same worker, which holds the USB mutex while it does so. The frame buffers are allocated by begin(); their number per direction is set with setBuffers() (TinyWifiDongleConfig::framesToHost and framesFromHost).

The TinyUSB callbacks are C functions, so the instance that ran begin() receives them.
