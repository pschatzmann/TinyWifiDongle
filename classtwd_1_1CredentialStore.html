Detailed Description

Keeps the name and password of one WiFi network in flash.

Uses the EEPROM emulation that both the ESP32 and the Raspberry Pi Pico cores provide, so no filesystem partition is needed. The data is marked, so flash that was never written by this class reads as "nothing saved".
