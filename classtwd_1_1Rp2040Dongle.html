Detailed Description

Raspberry Pi Pico W / Pico 2 W dongle: raw Ethernet frames between USB and WiFi. 

Rp2040UsbNcm (UsbTransport) <-> L2Bridge <-> Rp2040WifiFrameLink (FrameLink)

The USB adapter takes the WiFi chip's station MAC address; the host does its own DHCP/DNS with the WiFi network. The board has no IP address of its own. Needs the core option "USB Stack: Pico SDK" (the default).

The settings manageUsb, pinUsbTask, stallTimeoutMs and usbMaxFrame of the configuration only apply to the ESP32 and are ignored here; framesToHost and framesFromHost only apply here.
