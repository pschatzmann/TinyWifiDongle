Detailed Description

Layer-2 bridge between the USB host and the uplink network. 

Host <-- UsbTransport <-- L2Bridge --> FrameLink --> access point

Frames are forwarded unchanged in both directions: no IP stack, NAT or DHCP server on the MCU, so the host gets its address from the uplink network's own DHCP server. Two rules keep an access point happy:

  • the host adapter uses the link's MAC address (see UsbTransport::setHostMac), and frames from the host with any other source address are dropped;
  • frames from the link that carry that address as source are the access point echoing the host's own broadcasts, and are dropped.

Shared by all ports; they only provide a UsbTransport and a FrameLink.
