Detailed Description

Raw Ethernet access to the WiFi network through the CYW43 chip of the Pico W / Pico 2 W.

Joins the network with the core's WiFi class (which keeps its connect and retry logic) and then takes over the station's lwIP interface: its input function is replaced, so every frame the chip receives goes to the FrameReceiver instead of the IP stack, and its DHCP client is stopped. Frames are sent with cyw43_send_ethernet(). The board has no IP address of its own; the host behind the bridge uses the station's MAC address and asks the network itself.

A worker in the core's lwIP async context re-applies these changes twice a second, because the core may restart DHCP or reset the interface after a reconnect.

Also an Uplink, so the composition can report the association state.
