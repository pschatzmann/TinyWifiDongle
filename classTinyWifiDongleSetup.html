Detailed Description

Finds out which WiFi network to join: from flash, or from the user through a setup page.

begin() uses the network saved in flash. If there is none, the board opens its own WiFi network (the "setup network"); a phone or laptop that joins it is led to a page on which the user picks a network and enters the password. The choice is saved in flash, so the next start needs no setup.

The setup page needs the board to have an IP address, which the bridge of TinyWifiDongle never has. So the setup runs first and the dongle takes over the WiFi chip afterwards; the USB adapter does not exist while the setup runs.

TinyWifiDongle dongle;
TinyWifiDongleSetup wifiSetup;
void setup() {
wifiSetup.begin();
dongle.begin(wifiSetup.ssid(), wifiSetup.password());
}
void loop() {
bool connected = dongle.isWifiConnected();
wifiSetup.update(connected);
delay(connected ? 1000 : 100);
}
