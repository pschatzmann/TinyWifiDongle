Detailed Description

Captive portal in which the user picks a WiFi network and enters its password.

run() scans for networks, opens an access point, answers every DNS query with the board's own address (so a phone or laptop that joins the access point opens the page by itself) and serves a small form until the user has submitted a network. Built from the web server, DNS server and WiFi classes that the ESP32 and the Raspberry Pi Pico cores both contain.
