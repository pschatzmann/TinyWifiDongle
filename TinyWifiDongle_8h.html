Detailed Description

Header-only USB WiFi dongle for Arduino.

The microcontroller joins a WiFi network and presents itself to a host computer as a USB network adapter (CDC-NCM). Ethernet frames are forwarded unchanged between USB and WiFi (a layer-2 bridge), so the host is a normal client of the WiFi network and gets its address from that network's DHCP server. The MCU itself has no IP address:

Host PC <-USB NCM-> [ L2 bridge ] <-> [ WiFi STA ] <-> access point

Each MCU family supplies a "port" (ports/TinyWifiDonglePort{Mcu}.h) with the same small contract:

bool begin(const TinyWifiDongleConfig&) start USB and WiFi, bridge them bool usbReady() host has enumerated the device bool uplinkConnected() WiFi is associated

Because the library is header-only and defines USB driver callbacks, include it from exactly one translation unit (the sketch's .ino).
