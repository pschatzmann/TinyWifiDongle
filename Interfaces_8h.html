Detailed Description

Portable abstractions the dongle is built from.

Host <–USB--> UsbTransport <--> L2Bridge <--> FrameLink <–WiFi--> access point

Every MCU port provides implementations of UsbTransport, FrameLink and Uplink; the classes in core/ only depend on these interfaces.
