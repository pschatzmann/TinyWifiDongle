TinyWifiDongle

A header-only C++ Arduino library that turns a microcontroller into a USB WiFi dongle: the MCU joins a WiFi network and appears to your PC as a USB network adapter (CDC-NCM).

  • No driver needed on the PC: Linux, macOS and Windows 11 have a CDC-NCM driver built in
  • Ethernet frames are bridged unchanged between USB and WiFi, so the PC is a normal client of your WiFi network and gets its address from your router's DHCP server. The MCU itself has no IP address
  • Speed is limited by the full-speed USB (12 Mbit/s) of these chips: about 600 KB/s on the ESP32-S3 and about 250 KB/s on the Pico 2 W in the tests. Fine for browsing and downloads, but much slower than a PC's own WiFi (details)
  • Messages go to any Print the sketch passes to TWD_LOGGER, e.g. a UART or a USB serial port (details)
  • Credentials can be hard-coded or entered in a browser on a setup page the board opens itself (details), with no additional library

Supported platforms

Platform Arduino core State
ESP32-S3, ESP32-S2 arduino-esp32 3.x (tested 3.3.12) works, tested on an ESP32-S3
Raspberry Pi Pico 2 W (RP2350), Pico W (RP2040) arduino-pico (tested 6.3.1) works, tested on a Pico 2 W; the Pico W is untested
ESP32-P4 arduino-esp32 3.x compiles, WiFi side tested; the USB side needs a board with a USB-OTG connector

Not supported: the original ESP32, ESP32-C3/C6 and other chips without a USB device controller that can carry a network class, the Raspberry Pi Pico without WiFi, and the Arduino mbed cores. Details and test results are in Status.

Example

#include "TinyWifiDongle.h"
TinyWifiDongle dongle;
void setup() {
dongle.begin("ssid", "password");
}
void loop() {}

Board settings (the board is then connected to the PC with its USB connector):

  • ESP32-S2/S3: board option USB Mode: USB-OTG (TinyUSB), connect the USB-OTG port
  • Raspberry Pi Pico W / Pico 2 W: the default option USB Stack: Pico SDK, connect the USB connector of the board

Installation in Arduino

You can download the library as zip and call Sketch -> Include Library -> Add .ZIP Library. Or you can git clone this project into the Arduino libraries folder e.g. with

cd ~/Documents/Arduino/libraries
git clone https://github.com/pschatzmann/TinyWifiDongle.git

I recommend to use git because you can easily update to the latest version just by executing the git pull command in the project folder.

Requirements:

  • ESP32: ESP32 board package (arduino-esp32) 3.x, tested with 3.3.12. It must include the TinyUSB NCM class, which is on in the prebuilt libraries. Board option USB Mode: USB-OTG (TinyUSB), with the USB-OTG port of the board connected to the PC
  • Raspberry Pi Pico W / Pico 2 W: the arduino-pico core (Raspberry Pi Pico/RP2040/RP2350), tested with 6.3.1, board "Raspberry Pi Pico W" or "Raspberry Pi Pico 2W" with the default option USB Stack: Pico SDK. The board's single USB connector carries the adapter
  • Include TinyWifiDongle.h from the sketch only, because the header defines the USB driver callbacks (both platforms)

Host support for CDC-NCM: Linux and macOS native, Windows 11 native (Windows 10 needs a driver).
