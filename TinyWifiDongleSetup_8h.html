Detailed Description

Lets the user enter the WiFi credentials in a browser instead of hard-coding them.

Separate from TinyWifiDongle.h, so sketches that do not need it do not pull in the web server. Works on the ESP32 and on the Raspberry Pi Pico W / Pico 2 W and needs no additional library.
