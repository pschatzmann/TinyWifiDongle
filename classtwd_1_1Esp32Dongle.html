Detailed Description

ESP32-S2/S3 dongle: raw Ethernet frames between USB and WiFi. 

Esp32UsbNcm (UsbTransport) <-> L2Bridge <-> Esp32WifiFrameLink (FrameLink)

The USB adapter takes the WiFi station's MAC address; the host does its own DHCP/DNS with the WiFi network. The MCU has no IP address of its own.
