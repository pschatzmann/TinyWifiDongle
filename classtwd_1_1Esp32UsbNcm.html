Detailed Description

USB CDC-NCM network device for the ESP32-S2/S3 (TinyUSB).

Implements UsbTransport on top of the TinyUSB NCM class that the Arduino core ships:

  • registers the NCM interface and its descriptors,
  • queues outgoing frames and feeds them to the driver, one frame per USB transfer, from the TinyUSB task,
  • re-arms reception after every frame,
  • re-enumerates the device if the send path stalls for longer than the stall timeout (1 second by default, see setStallTimeout()).

The TinyUSB callbacks are C functions, so the class is a singleton in effect: the instance that ran begin() receives them.

◆ logControllerState()

void twd::Esp32UsbNcm::logControllerState ( )
inline

Logs the USB controller's registers of the data IN endpoint: control, transfer size, interrupt flags, FIFO space, and the interrupt masks. A debugging aid for a stalled send path. Only available on the ESP32-S2/S3, where the controller sits at a known address; on other chips it only reports that.
